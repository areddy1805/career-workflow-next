# Career Workflow v4.0.0 Release Notes

Welcome to **v4.0.0**! This is the most significant milestone in the history of the Career Workflow project. What started as a CLI auto-apply script has been completely re-engineered into an **AI-powered Job Operations Platform**.

## Highlights

### 🚀 Runtime v2 Engine
The heart of the application is completely rebuilt. Domain logic (acquisition, classification, application) is now strictly decoupled from presentation. The new event-driven architecture uses an internal **EventBus** and a **Runtime State Manager** to safely transition process states. 

### 🎛️ Operations Center
No more staring at scrolling logs. We've introduced a 16-surface React application that provides:
- Live visibility into the executing pipeline.
- Interactive queues for manual application review.
- High-level funnel conversion analytics.
- Real-time LLM token cost intelligence.

### 🧠 Multi-Provider Inference
The Inference Platform has been upgraded to an `OpenAICompatibleProvider` architecture.
- **DeepSeek First**: The system natively defaults to `deepseek-v4-flash`, reducing execution costs dramatically while improving candidate-aware semantic evaluation.
- **Graceful OMLX Fallback**: In the event of API degradation, the system seamlessly routes requests to a local proxy (`qwen3.5-4b`).

### 📒 Decision Ledger & Unified Reporting
The `Decision Ledger` is now backed by a transactional SQLite WAL engine. Duplicate submissions are cryptographically impossible. Furthermore, a **Unified Runtime ViewModel** streams live state to both the Rich CLI and the Operations Center, ensuring all user interfaces reflect identical operational truths.

### 🎨 Rich CLI Experience
For those who prefer the terminal, the `cw` CLI has been upgraded with the `rich` library. The terminal now renders progress bars, job pipelines, timelines, and efficiency metrics without stutter or console noise.

## Migration Notes
- Ensure your `.env` contains `DEEPSEEK_API_KEY`.
- You will need to start both `uvicorn api.main:app` and `npm run dev` to fully utilize the Operations Center.
- Run `cw doctor` to verify system health before starting your first v4.0.0 pipeline execution.
