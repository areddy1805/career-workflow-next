# ADR-011: Greenfield Persisted Learning System

**Status:** ✅ Frozen
**Date:** 2026-08-02
**Supersedes:** None

## Context

Existing learning primitives are stubs: `LearningLedger` is an in-memory list, `LightGBMRanker` is a weighted-average placeholder, adaptive strategy is computed but not consumed, and `learning_bias = 0.0` is not persisted. Silent regressions are unacceptable (AGENTS.md).

## Decision

CareerFlow builds a **persisted learning system**: outcome store, signal collection, bounded/monotonic ranking feedback, answer weighting, and provider/ATS success analytics. It replaces the stubs; all feedback is flag-gated and reversible (bias=0 ⇒ behavior identical to today).

## Alternatives Considered

- Ship the stubs — rejected: fake learning is worse than none.
- Deep RL-style retraining — rejected: over-engineering for v1.

## Tradeoffs

- **Gained:** real improvement loop, calibration, auditability.
- **Sacrificed:** the 0.0-learning baseline is retired.

## Consequences

- Ranking feedback bounded and monotonic; regression suite must stay green at bias=0.
- Calibration measured against actual outcomes (metric `16_SUCCESS_METRICS.md`).
