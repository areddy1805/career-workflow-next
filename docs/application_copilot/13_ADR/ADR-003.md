# ADR-003: Local Backend Agent (Playwright via FastAPI)

**Status:** ✅ Frozen
**Date:** 2026-08-02
**Supersedes:** None
**Related:** ADR-002

## Context

The browser component must run somewhere: browser extension, desktop wrapper, or a local agent driven by the existing FastAPI backend.

## Decision

The assistant is a **local backend agent**: Playwright driven by the FastAPI process on the user's machine, launching a **visible browser the human can take over at any moment**.

## Alternatives Considered

- **Browser extension** — Rejected: weaker DOM/state control, no Python coupling, extension-review friction, harder to share the Answer Bank/evidence stack.
- **Desktop wrapper (Tauri/Electron)** — Rejected for v1: heavier build surface; no clear benefit over the FastAPI-hosted agent for a single-user local tool.

## Tradeoffs

- **Gained:** full control, shared evidence stack, Python typing, no distribution friction.
- **Sacrificed:** portable UI; requires the backend running (already true for CareerFlow).

## Consequences

- Playwright is a new dependency (pinned).
- One browser session at a time; sessions serialized.
- Browser visible; take-over is a first-class action.
