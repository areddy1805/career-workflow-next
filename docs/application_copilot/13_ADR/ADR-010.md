# ADR-010: Local-First SQLite (copilot.db)

**Status:** ✅ Frozen
**Date:** 2026-08-02
**Supersedes:** None

## Context

The Copilot needs its own persisted state (opportunities, briefs, answers, sessions, learning, events) without disturbing pipeline DBs and without a new server dependency.

## Decision

All Copilot state lives in a **local SQLite database** (`data/copilot.db`, WAL, migration runner). No new JSON state files. Schema frozen in `02_ARCHITECTURE.md` §7.8.

## Alternatives Considered

- Postgres/Redis — rejected: over-provisioned for single-user local.
- JSON files — rejected: inconsistent with the "ledger is truth" rule.

## Tradeoffs

- **Gained:** simplicity, locality, privacy, atomicity.
- **Sacrificed:** concurrency (fine — single-user serialized).

## Consequences

- PII stays on the machine (privacy win).
- Future multi-tenant can migrate per-tenant tables.
