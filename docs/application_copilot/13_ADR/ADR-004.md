# ADR-004: Source Tiering (Tier 1/2/3)

**Status:** ✅ Frozen
**Date:** 2026-08-02
**Supersedes:** None

## Context

Fifteen+ sources are claimed. Shipping all at parity is impossible in one cycle; some are hostile to automation.

## Decision

- **Tier 1 (must, v1):** Manual Queue, Generic Job URL, LinkedIn URL, Wellfound URL, Company Careers URL, Pasted JD text, PDF JD — full normalize + assist.
- **Tier 2 (native, v1):** Greenhouse, Lever, Ashby — ATS adapters as optimizations.
- **Tier 3 (assist-only, v1):** Workday, Rippling — checkpoint/guidance only.
- **Not in v1:** LinkedIn auto-submit, Workday autonomous, bulk automation.

## Alternatives Considered

- ATS-first (Greenhouse/Lever/Ashby before URL/text) — rejected: Tier 1 sources are the actual acquisition surface today.
- All-sources parity — rejected: unbounded scope.

## Tradeoffs

- **Gained:** a shippable, high-value surface fast.
- **Sacrificed:** Workday/Rippling/LinkedIn full automation (explicit non-goals).

## Consequences

- Adapter pattern makes future sources drop-in.
- Tier 3 degrades to guidance; never fights anti-bot.
