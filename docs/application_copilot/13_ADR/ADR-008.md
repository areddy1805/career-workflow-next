# ADR-008: Canonical CopilotOpportunity + Field Provenance

**Status:** ✅ Frozen
**Date:** 2026-08-02
**Supersedes:** None

## Context

Fifteen+ sources produce heterogeneous data; trust requires knowing where each fact came from.

## Decision

One canonical `CopilotOpportunity` model (frozen in `03_OPPORTUNITY_MODEL.md`). Every field carries **provenance** (`parser|provider|llm|human`) and **confidence**. Derived fields are always recomputed, never stored as source facts.

## Alternatives Considered

- Reuse thin `ApplicationOpportunity` — rejected: insufficient content (no comp/skills/content).
- Per-source models — rejected: fragments the assistant.

## Tradeoffs

- **Gained:** one code path, explicit trust.
- **Sacrificed:** migration from pipeline opportunity view (adapter does it).

## Consequences

- Fingerprinting + dedup defined (`03_OPPORTUNITY_MODEL.md`).
- Brief renders provenance per section.
