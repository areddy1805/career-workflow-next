# ADR-009: Answer Bank Built on HybridQuestionResolver

**Status:** ✅ Frozen
**Date:** 2026-08-02
**Supersedes:** None

## Context

The pipeline already ships a gold-standard question-resolution stack (deterministic rules → LLM → safety gate → canonicalize → shape validation → constraints → serialize, with confidence + manual_review).

## Decision

The Answer Bank uses `HybridQuestionResolver` as its **resolution engine** and `CANDIDATE_EVIDENCE`/`CandidateIntelligence` as the **truth source**. CareerFlow adds persistence, fingerprinting, per-profile namespaces, confirmation workflow, and a learning-quality loop — it does not reimplement resolution.

## Alternatives Considered

- Standalone LLM-based answerer — rejected: fabrication risk, cost, loses proven guardrails.
- Deterministic only — rejected: can't cover descriptive questions.

## Tradeoffs

- **Gained:** safety, truthfulness, reuse, faster.
- **Sacrificed:** some coupling to pipeline resolver (accepted; it's a stable, read-only call).

## Consequences

- Generated answers are cached by `(fingerprint, profile_id)`.
- Exact-metric and sensitive answers are never invented (locked to manual).
- Guardrail audit is a hard success metric.
